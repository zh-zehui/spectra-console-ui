# SPECTRA · 频谱智能观测台

本文说明现有设备的连接和操作。从代码准备边缘端环境请先阅读 [Jetson 部署指南](edge-deployment.md)；实际部署源码已加入仓库的 [`edge/`](../edge/)。

## 启动与停止

- 双击 `Open-Spectra.cmd`：确保 Jetson 上的任务 API（8765）和可视化网关（8780）运行，复用已有本机端口转发或建立 SSH 隧道，并打开本机页面。不会自动启动射频采集。
- 双击 `Stop-Spectra.cmd`：调用 Jetson 的 `scripts/stop-ui-stack.py`，仅停止属于该工程的 API/UI，并关闭匹配本平台别名和端口的独立 SSH 隧道。活动/排队任务或手动 Harness 尚在运行时会拒绝停止，需先取消或结束任务。
- `powershell -NoProfile -ExecutionPolicy Bypass -File .\Stop-Spectra.ps1 -CheckOnly`：只检查任务、服务和独立隧道，不改变运行状态。
- 若8780由 Cursor/VS Code 的远程端口转发提供，停止脚本保留编辑器；可在编辑器“端口”面板中关闭该转发。停止平台后页面将无法访问，已有源码、IQ、报告与配置保留。
- 当前未配置 Jetson 开机自启；关闭浏览器不会停止平台。Harness按任务启动，不是单独常驻的交互界面。

独立可视化操作层；官方 DeepSeek Harness 保持 headless。dist 为不依赖构建的 HTML/CSS/JavaScript，云端发布版仅提供明确标注的交互演示。本机入口通过 SSH 隧道连接 Jetson 上的独立可视化网关，可查看真实历史任务并提交、取消接收分析任务。

界面支持提示词与采集参数、时频图缩放平移、分割边界和识别证据叠加、阶段切换及迭代回放、信号筛选、证据联动、历史任务、阶段耗时、JSON 报告导出、展示模式和响应式布局。

## 本机连接真实设备

在这台 Windows 本机运行 `Open-Spectra.ps1`。使用已有 SSH 别名 Jetson-server-new，不改 SSH 配置。优先使用 http://127.0.0.1:8780/；若该端口被失效的编辑器转发占用，或 Windows 不允许绑定，则自动选择可用端口并打开实际网址。当前电脑可使用 http://127.0.0.1:18780/。脚本会记住并复用健康连接，实际网址记录在本机 `.spectra-launcher.json`，不提交到源码。真实模式下手动点击“启动真实任务”才采集。

Jetson 网关：/home/sribd/spectrum_agent/src/spectrum_agent/ui_gateway.py，静态页面：/home/sribd/spectrum_agent/ui/dist。网关只监听 127.0.0.1:8780；调用本机任务 API 127.0.0.1:8765。DeepSeek 和任务 API 密钥始终留在服务端。云端演示站不代理访问私网设备。

## 数据与边界

真实时频图由任务 IQ 分段计算 STFT 并按显示分辨率最大池化，功率未做绝对校准，纵轴为文件采样时间。初始检测、局部替代候选及有效帧证据分开保存；复查候选不自动替换初始分割。目录默认展示最强200个初始谱迹及有效帧，提示展示数量；完整原始事件保存在导出报告中。有效帧与谱迹重叠不等于整条谱迹已确认为该协议。名义时间容差未经过所有真实信道条件校准。

历史 v0.5 Wi-Fi 接收器存在未完成排查的重复采样偏移稳定性问题，因此接收器仍标记实验性；没有有效帧不代表该协议不存在。界面不掩盖 partial/failed/unknown，不以图像外观确认协议。

瀑布图操作：最新采样时间在上方。图内滚轮同时缩放频率和时间；横轴或 PSD 上滚轮只缩放频率，纵轴或 Shift+滚轮只缩放时间。拖动图面可沿双轴平移，复位视图恢复完整范围。坐标、分割框和点击选区共用时间映射，原始报告的时间仍按采集先后记录。
